구글 시트 연동 설정

선생님께서 제공해 주신 연동 URL을 입력하면 자동 저장됩니다.

구글 시트 연동 5단계 가이드

1. 구글 스프레드시트 만들기

새 구글 시트를 만들고 1행(헤더)에 순서대로 입력합니다:
이름 | YY | Yy | yy | 노란색 | 초록색 | 총횟수 | 일시

2. Apps Script 열기

상단 메뉴 [확장 프로그램] ➔ [Apps Script]를 클릭합니다.

3. Code.gs 붙여넣기

제공된 Apps Script (Code.gs) 코드를 에디터에 전체 붙여넣고 저장(Ctrl+S)합니다.

4. 웹 앱 배포하기

우측 상단 [배포] ➔ [새 배포] ➔ 유형: 웹 앱
- 실행 수행자: 나 (Me)
- 액세스 권한: 모든 사용자 (Anyone) 설정 후 배포 클릭!

5. URL 등록하기

발급된 웹 앱 URL (https://script.google.com/macros/s/.../exec)을 복사하여 본 앱의 [설정] 창에 입력하세요.
